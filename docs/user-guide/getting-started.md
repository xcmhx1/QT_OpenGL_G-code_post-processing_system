# 快速开始

## 1. 界面区域

- **默认**：绘图、修改、图层和图元属性。
- **机加工**：导入导出、排序、几何处理和 G-code 模式。
- **显示**：背景网格、加工箭头、加工编号、加工断面和排除状态。
- **右侧加工设置**：导入后自动处理、导出习惯和方管截面状态。
- **底部状态区**：坐标、捕捉、正交、极轴追踪和命令提示。
- **画布右上角视图方块**：切换顶、底、左、右、前、后等标准视角。

## 2. 打开文件

1. 使用“文件 → 导入文件”，或将 DXF/DWG 文件拖入画布。
2. 最近成功打开的文件可从“文件 → 最近打开”再次打开。
3. 导入完成后检查图元数量、位置、图层和曲线形状。
4. 需要清理完全重叠图元时，使用“机加工 → 去重”。

导入后自动去重、自动识别方管截面等选项位于右侧“加工设置”。自动处理失败不会撤销已经成功读取的文件，应根据命令栏提示继续检查。

## 3. 平面三轴流程

```text
导入或绘制
→ 检查并编辑图形
→ 选择 3轴 模式和当前配置
→ 设置加工方向或起点
→ 普通排序或智能排序
→ 检查加工单元编号和箭头
→ 导出 G-code
```

## 4. 方管四轴流程

普通四轴可直接使用有效路径、旋转轴中心和运动配置：

```text
导入和检查
→ 选择 4轴(绕A)
→ 设置运动安全和四轴参数
→ 排序
→ 检查 XYZ/A 方向
→ 导出 G-code
```

需要表面归属、圆角方向、内部线、加工断面或懒旋转时：

```text
识别或手动设置方管截面
→ 清理内部线
→ 识别或指定加工断面
→ 设置截面增强工艺
→ 重新排序并检查
→ 导出 G-code
```

## 5. 导出前检查

- 当前模式与目标机床一致。
- 当前配置中的旋转轴中心、方向和安全距离正确。
- 加工编号连续，方向箭头符合预期。
- 内部线已清理，废面和加工断面状态正确。
- 闭合路径完整回到入口，需要时包含过切。
- 不连续加工单元之间存在安全转移。
