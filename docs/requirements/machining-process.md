# 加工工艺需求

本文件统一规定用户工艺设置如何进入排序、轨迹和 G-code 导出。
加工几何能力见[加工功能需求](./machining.md)，代码配置与文本输出见[G-code 与导出需求](./gcode-and-export.md)。

## 1. 工艺设置范围

### PROCESS-001 用户加工设置

用户可设置图元是否加工、加工方向、加工起点、内部线排除、加工断面和废面。以上设置必须作用于当前文档，文档切换后按新文档状态重新建立。

### PROCESS-002 方管截面来源

方管截面可由自动识别、选中图元识别或手动输入 Y 长、Z 宽和圆角半径建立。手动输入时，截面中心优先沿用当前已识别中心；当前没有已识别中心时使用四轴配置中的旋转轴 Y/Z 中心。

### PROCESS-003 手动设置优先

用户已应用的手动截面、加工启用、内部线、加工断面和废面设置必须作为后续处理的明确输入。手动加工顺序和加工方向的优先级由所选排序入口决定。

### PROCESS-004 手动加工顺序

系统必须提供便捷的手动加工顺序设置。用户应能够对选中图元或加工组指定顺序、调整前后位置、清除人工顺序，并在画布中立即查看结果。

### PROCESS-005 智能排序

智能排序仅使用当前几何和有效工艺约束重新计算顺序与方向，不考虑用户此前设置的人工加工顺序和人工加工方向。加工启用、内部线排除、加工断面和废面状态继续有效。

### PROCESS-006 普通排序

普通排序必须以人工加工顺序和人工加工方向为第一优先级。系统先固定用户已经明确设置的顺序与方向，再对未设置部分执行自动补充排序，且不得改变已固定结果。

### PROCESS-007 自动排序策略

需要系统自动决定顺序的部分可使用最近距离或懒旋转策略。懒旋转默认关闭，其具体表面排序行为由 [MACH-031](./machining.md#mach-031-可选懒旋转工艺) 规定。

### PROCESS-008 过切

过切是闭合加工组的可选工艺。过切距离为 0 时关闭；大于 0 时，闭合组先准确回到起点，再沿原加工方向继续指定距离。开放路径仅执行正常终点收刀。

### PROCESS-009 离轴额外距离

离轴额外距离是四轴安全移动的可选附加量。系统必须在不连续加工组之间的安全移动中使用该值，连续加工组内部保持连续切割。

### PROCESS-010 加工面 Z 修正

加工面 Z 修正是四轴加工位置的可选补偿。正负修正值必须统一作用于当前加工轨迹，并在安全位置计算和最终输出中保持一致。

## 2. 排除与工艺屏障

### PROCESS-011 内部线排除

被标记为内部线的图元仅从加工计划中排除，CAD 图元继续保留并可恢复。内部线不参与排序、轨迹和 G-code，也不显示加工方向或序号。

### PROCESS-012 废面排除

废面及其当前规则覆盖的加工内容仅作为排除对象，不进入普通加工组或加工断面工艺。

### PROCESS-013 加工断面工艺

加工断面作为工艺屏障独立参与计划。系统必须先完成该断面之前所属加工段内的普通加工内容，再加工断面，并继续处理下一加工段。

### PROCESS-014 连续性优先

普通路径形成连续链或闭环时，必须作为连续加工组处理。连续组内部的连接关系优先于普通距离优化和懒旋转表面分组。

## 3. 工艺应用顺序

系统必须按以下顺序建立加工结果：

1. 读取当前文档几何和用户加工设置；
2. 确定有效方管截面，手动截面优先；
3. 排除未启用图元、内部线和废面相关内容；
4. 验证加工断面并建立加工段工艺屏障；
5. 提取连续链、闭环和普通加工组；
6. 按用户选择执行普通排序或智能排序，并对自动决定部分应用最近距离或懒旋转策略；
7. 根据离轴额外距离、加工面 Z 修正和过切生成机床运动；
8. 将最终运动和代码规则转换为 G-code 文本。

每一步仅使用前一步确认后的有效结果。任一步失败时，后续步骤停止，导出入口不得使用部分结果。

## 4. 状态与重新计算

### PROCESS-015 计划失效

几何、方管截面、加工启用、方向、起点、内部线、加工断面、废面或排序方式发生变化后，当前加工计划必须失效。

### PROCESS-016 参数重新生效

过切、离轴额外距离或加工面 Z 修正变化后，后续轨迹和导出必须使用新值；界面不得继续导出旧参数生成的结果。

### PROCESS-017 模式一致

三轴和方管四轴必须使用各自当前有效的工艺设置。模式切换后，仅允许导出与当前模式一致的排序和轨迹。

### PROCESS-018 用户检查

排序完成后，系统应显示当前加工顺序、方向、加工断面和排除状态。用户确认后才能进入最终导出操作。

## 5. 一致性要求

- 排序、轨迹和导出必须使用同一组用户工艺设置；
- 自动导入处理不得静默覆盖已经应用的手动设置，用户显式重新识别时可替换手动截面；
- 计划失效后必须重新排序或重新生成轨迹；
- 文本输出阶段仅格式化最终工艺结果，不重新选择排序方式或加工方向；
- 错误信息应指出失效或失败所在阶段，便于用户修正设置后重新执行。
