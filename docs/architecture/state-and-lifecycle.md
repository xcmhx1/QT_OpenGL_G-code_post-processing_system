# 状态与生命周期

## 1. 稳定身份与 Viewer 临时身份

系统区分两类身份：

| 身份 | 生命周期 | 用途 |
| --- | --- | --- |
| 稳定图元身份 | 贯穿文档、加工状态和派生结果 | 关联 CAD 图元、加工计划、机床轨迹和 NC |
| Viewer 临时身份 | 当前对象和显示缓存生命周期 | 渲染缓存、拾取、选择和 GPU 资源定位 |

加工状态、计划、轨迹和 NC 仅使用稳定图元身份。Viewer 临时身份仅在显示边界内使用，不跨对象生命周期保存，也不进入加工数据链。

## 2. 文档内容状态

以下操作改变 CAD 文档内容：

- 导入或清空文档；
- 新增、删除和复制图元；
- 移动、旋转、缩放、镜像等几何编辑；
- 图层和颜色修改；
- Undo/Redo。

文档内容变化后，旧几何捕获结果和基于旧文档生成的加工计划失效。批量操作作为一次业务动作推进一次内容状态，避免中间状态被误认为完整结果。

## 3. 用户加工状态

以下变化属于加工输入变化：

- 加工启用；
- 加工方向；
- 加工起点；
- 人工加工顺序；
- 内部线；
- 方管截面；
- 加工断面；
- 废面；
- 排序方式。

用户加工状态与 CAD 几何共同决定加工计划。选择状态和 Viewer 显示开关仅改变交互或展示，不改变加工业务输入。

## 4. 派生结果与失效关系

加工计划、机床轨迹、NC 程序和 G-code 文本依次派生：

```text
CAD 文档内容 + 用户加工状态
→ 加工计划
→ 机床轨迹
→ NC 程序
→ G-code 文本
```

状态失效遵循上游变化使下游结果失效的原则：

| 变化 | 失效结果 | 保留内容 |
| --- | --- | --- |
| 文档几何、图层或颜色变化 | 旧加工计划、轨迹、NC 和导出结果 | 仍可关联的用户加工输入 |
| 加工启用、方向、起点或人工顺序变化 | 旧加工计划、轨迹、NC 和导出结果 | CAD 文档内容 |
| 内部线、加工断面或废面变化 | 旧加工计划、轨迹、NC 和导出结果 | CAD 图元和当前标记输入 |
| 方管截面变化 | 依赖截面的分析、计划、轨迹和 NC 结果 | 普通四轴所需的其他输入 |
| G-code 配置变化 | 旧 NC 文本输出 | CAD、加工计划和可复用轨迹语义 |

失效仅清除或拒绝使用派生结果，不反向删除用户输入。重新生成时，系统使用当前文档、当前加工输入和当前配置建立新结果。

## 5. 方管截面状态

方管截面包含：

- Y 方向尺寸；
- Z 方向尺寸；
- 圆角半径；
- 截面中心 `(Ycenter, Zcenter)`。

截面输入来源优先级为：

1. 用户当前明确指定的截面参数；
2. 当前有效的自动识别结果；
3. 中心缺失时使用 `(0, 0)`。

自动识别结果不得静默覆盖用户已经确认的手动截面。用户修改截面后，所有依赖旧截面的增强分析和派生结果失效。

没有有效截面尺寸和圆角时，普通四轴排序、轨迹和 G-code 导出仍可使用旋转轴中心及运动配置继续运行。表面归属、圆角刀头方向、方管实体内部路径、加工断面、废面和增强安全位置等截面增强功能不可运行。

## 6. 加工展示状态

加工顺序、方向、连续组和计划排除项从当前有效加工计划生成显示快照。内部线等即时用户加工状态即使使旧计划失效，也应继续通过当前业务状态显示。

Viewer 展示快照随有效计划更新或清除。展示快照仅反映业务状态，不承担计划或加工输入的持久化职责。
