# 问题排查

## 1. 方管截面已过期

文档几何在识别后发生了变化。重新识别或重新应用手动截面，然后重新排序。

## 2. 候选路径存在未连接间隙

候选边界没有满足严格闭合要求。

处理步骤：

1. 放大检查报告位置附近的端点。
2. 删除重复边或无关支线。
3. 修正真实间隙，使相邻图元端点重合。
4. 重新识别截面或加工断面。

连接搜索容差不会把可测量的工程间隙自动修补为闭环。

## 3. 未执行内部线条清理

当前没有有效方管截面，或截面在几何变化后已过期。先识别或应用手动截面，再执行“清理内部线条”。

## 4. 内部图元仍被保留

当前规则只删除完整位于内缩窗口内的图元。以下图元会保留：

- 接触或穿越窗口边界；
- 位于圆角安全带附近或方管表面；
- 属于加工断面或废面；
- 圆角半径过大导致窗口坍缩时不删除任何图元。

## 5. 加工单元没有唯一生产区位

该提示通常出现在启用懒旋转后，加工单元无法稳定归属一个方管区位。

检查：

- 方管截面是否有效且尺寸正确；
- 闭环成员是否真实连接；
- 是否存在重复图元；
- 路径是否跨越多个区位；
- 曲线是否误入方管内部。

当前工艺无需区位扫描时，可关闭懒旋转并重新智能排序。

## 6. 加工单元没有合法起刀点

检查加工单元入口是否位于其归属区位、闭环是否连续，以及当前安全转移配置能否到达该入口。修正图形或配置后重新排序。

## 7. 连续加工单元的实际路径不连续

源图形虽然接近连接，但转换后的机床位置或 A 轴姿态不连续。重点检查：

- 相邻图元是否属于正确方管表面或圆角；
- 是否有被排除的中间连接成员；
- 路径端点是否真实重合；
- 旋转轴中心和截面参数是否正确。

系统会停止导出，避免在加工开启状态下跨越不连续位置。

## 8. 看不到编号、箭头或排除颜色

在“显示 → 画布显示”中检查：

- 显示机加工相关；
- 加工方向箭头；
- 加工顺序编号；
- 加工断面标记；
- 废弃区域弱化。

这些开关只影响画布显示。

## 9. G-code 导出失败

1. 展开底部命令栏查看具体失败阶段和图元编号。
2. 确认当前模式与排序结果一致。
3. 确认相关几何或加工状态变化后已经重新排序。
4. 四轴检查旋转轴中心、安全距离、A 轴方向和连续路径。
5. 修正后重新导出。

导出失败时不会保留不完整文件。
