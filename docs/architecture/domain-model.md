# 领域模型

## 1. 核心概念

| 概念        | 拥有的业务事实                          | 主要关系               |
| --------- | -------------------------------- | ------------------ |
| CAD 文档    | 图元、图层、稳定图元身份和当前几何内容              | 是编辑、几何捕获和显示的文档来源   |
| 精确源几何     | 从 CAD 图元提取的精确业务几何                | 编译为统一加工路径          |
| 统一加工路径    | 规范方向的三维路径、闭合语义和源身份               | 供拓扑、加工分析、规划和轨迹生成使用 |
| 加工上下文      | 用户业务输入和自动分析状态                    | 与 CAD 几何共同构成加工计划输入 |
| 用户业务输入    | 用户明确设置、修正、清除或恢复的加工约束            | 解析时优先保护用户已经确认的业务决定 |
| 自动分析状态    | 截面和断面等自动分析结果                    | 提供候选事实，不覆盖对应的用户业务输入 |
| 加工单元      | 一个连续加工组或一个独立图元                  | 是排序和人工编排的最小单位       |
| 加工单元身份    | 加工单元全部稳定图元身份排序后的规范集合             | 用于在重新分析后匹配同一加工单元    |
| 加工单元序列    | 当前全部加工单元的唯一有序序列                 | 序列位置产生连续加工编号         |
| 加工计划      | 最终顺序、实际方向、实际起点、连续组、排除项和工艺屏障      | 驱动机床轨迹或三轴 NC 生成    |
| 机床轨迹      | XYZ/A 运动、安全移动、连续连接和过切            | 转换为 NC 程序语义        |
| NC 程序     | 与具体文本格式分离的运动和工艺语义                | 由后处理生成 G-code 文本   |
| G-code 文本 | 当前 NC 程序按所选配置格式化后的文件内容           | 是导出边界的最终结果         |

## 2. CAD 文档与稳定身份

CAD 文档保存当前可编辑内容。每个图元具有贯穿文档操作和加工链路的稳定业务身份，后续加工状态、计划、轨迹和 NC 通过该身份关联同一图元。

图层、颜色和原始几何属于文档内容。选择状态和 Viewer 临时缓存仅服务当前交互，不改变稳定业务身份。

## 3. 精确源几何与统一加工路径

精确源几何表示 CAD 图元在业务计算中的几何事实，隔离外部 DXF/DWG 对象和 Viewer 显示数据。

统一加工路径是拓扑、加工分析、规划和轨迹生成共同使用的路径表达。不同 CAD 图元通过统一转换进入同一条加工数据链，闭合状态和源图元身份随路径保留。

显示离散结果仅服务 Viewer。显示结果不替代精确源几何或统一加工路径。

## 4. 加工上下文

加工业务数据分为三类：

- 用户业务输入：加工启用、方向、起点、当前加工单元序列，以及方管截面、加工断面和废面；
- 自动分析状态：系统识别得到的截面、加工断面及其他分析结果；
- 派生加工结果：加工计划、机床轨迹、NC 程序和 G-code 文本。

用户业务输入和自动分析状态共同构成当前加工上下文。加工计划、机床轨迹和 NC 程序是加工上下文的输出，不属于加工上下文本身。

用户业务输入和自动分析状态在 Application 层解析为当前有效加工上下文。具体存储位置和类型映射由详细设计文档说明。

用户确认的截面、加工断面和废面优先于对应的自动识别结果。内部线自动清理直接删除窗口内图元并进入统一撤销栈。当前加工单元序列和方向的使用方式由排序入口决定：普通排序尽量保留当前序列、人工方向和人工起点，智能排序忽略当前序列并重新计算全部单元顺序。用户通过修改上游业务输入重新生成派生结果，派生结果不反向覆盖用户输入或自动分析状态。

## 5. 加工单元与序列

`ProcessUnit` 表示一个不可被排序拆分的加工单元。一个开放或闭合的连续加工组构成一个加工单元；与其他图元不连续的单个图元独立构成一个加工单元。每个参与加工的图元只属于一个加工单元。

`ProcessUnitKey` 由该加工单元全部稳定图元身份按确定顺序排列后形成规范集合。该身份不使用 Viewer 地址、临时显示键或当前序列位置。

`ProcessUnitSequence` 是 Application 层持有的唯一加工单元序列。加工编号由序列位置产生并始终为 `1..N`；插入、删除、移动或重新解析加工单元后立即重新编号。普通排序、智能排序和人工编排都以加工单元为最小单位。

## 6. 方管截面

方管截面由以下数据构成：

- Y 方向尺寸；
- Z 方向尺寸；
- 圆角半径；
- YZ 平面上的截面中心 `(Ycenter, Zcenter)`。

方管截面仅是截面增强四轴功能的输入，普通四轴加工链可以独立运行。截面来源优先级和缺省规则见[状态与生命周期](./state-and-lifecycle.md)。

## 7. 加工计划

加工计划将 CAD 几何、当前有效加工上下文和排序策略归并为可执行的加工决定，包括：

- 加工单元的最终序列；
- 实际加工方向和起点；
- 加工单元与成员图元的对应关系；
- 废面等排除项；
- 加工断面形成的工艺屏障。

加工计划是派生结果。文档内容或相关加工输入变化后，原计划失效并需要重新生成。

## 8. 机床轨迹、NC 程序与 G-code

四轴机床轨迹把四轴加工计划转换为机床运动，表达 XYZ/A 坐标、安全移动、连续连接和过切。普通四轴和截面增强四轴在此阶段使用各自有效的输入边界。

三轴加工计划直接生成三轴 NC 程序；四轴加工计划先生成机床轨迹，再生成四轴 NC 程序。NC 程序保存与文本方言无关的运动及工艺语义。G-code 文本由 NC 程序和当前代码格式规则生成。

## 9. 显示结果

加工顺序标签、方向箭头、断面标记和排除样式是加工状态或当前有效计划的可视化投影。一个加工单元只显示一个加工顺序编号。Viewer 读取加工单元身份和展示数据完成显示与交互，显示缓存和临时选择状态不参与加工事实判定。
