## 使用原则

- 先检查 CAD 图形，再建立加工顺序。
- 修改几何或加工状态后重新排序。
- 显示选项只改变画布显示，不改变加工结果。
- 自动识别和智能排序结果需要人工检查。
- G-code 用于实际加工前必须完成仿真、空跑和机床参数复核。
