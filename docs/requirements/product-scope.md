# 产品范围

## 1. 产品定位

本产品是面向 Windows 的桌面 CAD/CAM 软件，用于读取二维或空间曲线类 CAD 数据、完成常用编辑、组织加工顺序并导出客制化 G-code。

产品重点服务两类工作：

- 平面图形的三轴加工准备与代码导出；
- 特定方管工件绕 X 轴回转、使用 A 轴展开的四轴加工准备与代码导出。

## 2. 目标用户

- 需要查看和整理客户 DXF/DWG 图纸的机加工人员；
- 需要进行简单 CAD 修正和加工属性设置的工艺人员；
- 需要为平面或方管回转加工生成 G-code 的操作人员；
- 需要维护机床代码规则和加工配置的现场技术人员。

## 3. 主要业务场景

### SCOPE-001 文件准备

系统必须允许用户导入受支持的 CAD 文件，检查图元、修正几何并保存 DXF。

### SCOPE-002 平面加工

系统必须允许用户设置加工图元、方向和起点，生成三轴加工顺序并导出客制化 G-code。

### SCOPE-003 方管四轴加工

系统必须允许用户识别或手动设置方管垂直截面、排除内部路径、指定加工断面，生成符合当前方管工艺的四轴加工顺序和客制化 G-code。

### SCOPE-004 位图转 CAD

系统应允许用户导入位图，通过阈值、轮廓和折线处理生成可编辑的 CAD 轮廓。

### SCOPE-005 配置复用

系统必须允许用户保存、导入、选择和管理 G-code 配置，以适配不同现场代码规则。

## 4. 范围内能力

- CAD 文件导入、显示、保存和安全导出；
- 常用曲线图元创建、选择、捕捉和编辑；
- 图层、颜色和属性管理；
- Undo/Redo；
- 位图轮廓矢量化；
- 三轴加工排序与导出；
- 方管截面、圆角、内部线和加工断面处理；
- 方管四轴排序、轨迹和 G-code 导出；
- 加工顺序、方向和排除状态可视化；
- 浅色、深色和自定义外观；
- Lite/Pro 产品能力控制和本地许可证校验。

## 5. 人工兜底原则

### SCOPE-006 关键流程人工兜底

用户必须能够人工设置、修正、清除或恢复以下业务输入：

- 加工启用；
- 加工方向；
- 加工起点；
- 加工顺序；
- 内部线；
- 加工断面；
- 废面；
- 方管截面尺寸；
- 方管圆角；
- 方管截面中心。

自动处理失败后，用户应能够使用有效的人工业务输入继续后续流程。机床轨迹、安全移动、A 轴展开和最终代码属于派生结果，用户通过修改上述业务输入重新生成这些结果。人工输入必须经过与自动结果一致的有效性和安全校验。

## 6. 产品成功条件

- 用户能够从文件导入走完编辑、排序、检查和导出流程；
- 方管加工流程能够明确识别工件截面与工艺中断位置；
- 被排除图元仍保留在 CAD 文档中并可恢复；
- 文档或加工设置变化后，系统不得继续使用已失效的加工结果；
- 输出前向用户提供足够的顺序和方向检查信息；
