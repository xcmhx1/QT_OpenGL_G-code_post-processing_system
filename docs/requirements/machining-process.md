# 加工工艺需求

本文件统一规定用户工艺设置如何进入排序、轨迹和 G-code 导出。
加工几何能力见[加工功能需求](./machining.md)，代码配置与文本输出见[G-code 与导出需求](./gcode-and-export.md)。

## 1. 工艺设置范围

### PROCESS-001 用户加工设置

用户业务输入范围由 [SCOPE-006](./product-scope.md#scope-006-关键流程人工兜底) 定义。以上输入必须作用于当前文档，文档切换后按新文档状态重新建立。

### PROCESS-002 方管截面来源

方管截面参数包括 Y 方向尺寸、Z 方向尺寸、圆角半径和截面中心 `(Ycenter, Zcenter)`。来源优先级为：

1. 用户当前明确指定的截面参数；
2. 当前有效的自动识别结果；
3. 中心未指定时使用 `(0, 0)`。

用户必须能够单独修改截面中心。自动识别不得静默覆盖用户已经确认的手动截面。

### PROCESS-003 手动设置优先

用户已应用的手动截面、加工启用、内部线、加工断面和废面设置必须作为后续处理的明确输入。当前加工单元序列和人工方向、起点的优先级由所选排序入口决定。机床轨迹、安全移动、A 轴展开和最终代码仅由当前有效业务输入重新生成。

### PROCESS-004 加工单元序列人工编排

系统必须提供加工单元序列的人工编排。用户调整的是加工单元在唯一序列中的位置，编号始终由序列位置连续生成，不允许为图元或组成员单独保存稀疏优先级编号。

### PROCESS-005 智能排序

智能排序先建立加工单元集合，再仅使用当前几何和有效工艺约束重新计算全部加工单元顺序与方向。智能排序忽略当前加工单元序列和人工加工方向，结果直接替换当前序列；加工启用、内部线排除、加工断面和废面状态继续有效。

### PROCESS-006 普通排序

普通排序先建立加工单元集合，并尽量保留当前加工单元序列、人工加工方向和人工加工起点。新增或发生变化的加工单元由现有自动策略补入序列，已有且仍有效的加工单元保持相对顺序。

### PROCESS-007 自动排序策略

需要系统自动决定顺序的部分可使用最近距离或懒旋转策略。懒旋转默认关闭，且仅在有效方管截面能够确定表面归属时使用；具体行为由 [MACH-033](./machining.md#mach-033-可选懒旋转工艺) 规定。

### PROCESS-008 过切

过切是闭合加工组的可选工艺。过切距离为 0 时关闭；大于 0 时，闭合组先准确回到起点，再沿原加工方向继续指定距离。开放路径仅执行正常终点收刀。

### PROCESS-009 离轴额外距离

离轴额外距离是四轴安全移动的可选附加量。系统必须在不连续加工组之间的安全移动中使用该值，连续加工组内部保持连续切割。

### PROCESS-010 加工面 Z 修正

加工面 Z 修正是四轴加工位置的可选补偿。正负修正值必须统一作用于当前加工轨迹，并在安全位置计算和最终输出中保持一致。

## 2. 排除与工艺屏障

### PROCESS-011 内部线排除

被标记为内部线的图元仅从加工计划中排除，CAD 图元继续保留并可恢复。内部线不参与排序、轨迹和 G-code，也不显示加工方向或序号。

### PROCESS-012 废面排除

废面区间判断仅在方管截面有效时运行。截面无效时跳过废面相关判断，普通加工组继续处理。

### PROCESS-013 加工断面工艺

加工断面的识别、指定、扩展、验证、空间排序和工艺屏障仅在方管截面有效时运行。截面有效时，系统先完成断面之前所属加工段内的普通加工内容，再加工断面并继续下一加工段；截面无效时禁用相关操作，普通三轴和普通四轴继续运行。

### PROCESS-014 连续性优先

普通路径形成连续链或闭环时，必须形成一个不可拆分的加工单元。加工单元内部的连接关系优先于普通距离优化、懒旋转表面分组和人工编排。

## 3. 工艺应用顺序

系统必须按以下顺序建立加工结果：

1. 读取当前文档几何和用户业务输入；
2. 按来源优先级读取可选方管截面；
3. 截面有效时，按圆角半径安全内缩规则执行内部线清理；截面无效时跳过并提示；
4. 截面有效时执行加工断面和废面阶段；截面无效时跳过并提示；
5. 根据连续关系建立唯一的加工单元集合；
6. 按用户选择执行普通排序或智能排序，形成唯一的加工单元序列；
7. 生成普通四轴运动；截面有效时增加圆角刀头方向、真实碰撞边界和增强安全位置；
8. 根据离轴额外距离、加工面 Z 修正和过切生成最终运动；
9. 将最终运动和代码规则转换为 G-code 文本。

必需阶段失败时停止后续处理。截面增强阶段因截面无效而跳过时，普通四轴流程继续运行，且不得伪造方管尺寸、圆角或中心。

## 4. 状态与重新计算

### PROCESS-015 计划失效

几何、方管截面、加工启用、方向、起点、内部线、加工断面、废面、加工单元序列或排序方式发生变化后，当前加工计划必须失效。

### PROCESS-016 参数重新生效

过切、离轴额外距离或加工面 Z 修正变化后，后续轨迹和导出必须使用新值；界面不得继续导出旧参数生成的结果。

### PROCESS-017 模式一致

三轴和方管四轴必须使用各自当前有效的工艺设置。模式切换后，仅允许导出与当前模式一致的排序和轨迹。

## 5. 一致性要求

- 排序、轨迹和导出必须使用同一组用户工艺设置；
- 自动导入处理不得静默覆盖已经应用的手动设置，用户明确选择使用识别结果时可替换手动截面；
- 计划失效后必须重新排序或重新生成轨迹；
- 文本输出阶段仅格式化最终工艺结果，不重新选择排序方式或加工方向；
- 错误信息应指出失效或失败所在阶段，便于用户修正设置后重新执行。

## 6. 加工单元序列

### PROCESS-018 唯一加工单元序列

当前文档只存在一条 `ProcessUnitSequence`。顺序属于加工单元序列，不属于单个图元。

### PROCESS-019 连续编号

加工单元编号由序列位置产生，统一为 `1, 2, 3, ..., N`。编号不得缺失或重复，插入、删除和移动加工单元后必须立即重新编号。

### PROCESS-020 共同单元集合

普通排序、智能排序和人工编排必须先按同一连续关系建立加工单元集合。开放连续链、闭合连续组和独立单图元均使用相同的加工单元语义。

### PROCESS-021 智能排序替换

智能排序忽略当前加工单元序列，重新计算全部加工单元顺序，并用结果直接替换当前序列。系统不得保留隐藏的旧人工顺序。

### PROCESS-022 单元变化与重解析

连续关系变化后，系统必须根据 `ProcessUnitKey` 重新识别加工单元。仍存在的加工单元可按普通排序规则保留相对顺序，新增、拆分、合并或删除的单元必须重新纳入序列并连续编号。

### PROCESS-023 块内移尾

用户选择编号连续的一段加工单元后，可将范围内一个目标单元移动到该范围末位，其余单元保持相对顺序。目标必须位于所选范围内，操作后立即连续重编号。
