# 业务需求

本目录描述系统在业务层面必须提供的能力和必须遵守的产品边界。

## 文档范围

- [产品范围](./product-scope.md)：产品定位、目标用户、主要场景和范围边界。
- [文件和 CAD](./file-and-cad.md)：文件输入输出、图元支持和位图矢量化。
- [编辑与交互](./editing-and-interaction.md)：绘图、修改、选择、捕捉、视图和外观。
- [加工功能](./machining.md)：加工属性、排序、方管截面、加工断面和内部线。
- [加工工艺](./machining-process.md)：工艺参数、手动优先级、可选策略和排序到导出的生效流程。
- [G-code 与导出](./gcode-and-export.md)：配置管理、三轴与四轴输出和导出约束。

## 阅读规则

- “必须”表示当前产品流程不可缺少的行为或约束。
- “应”表示当前产品已经提供或应持续保持的业务能力。
- “仅”表示产品能力或数据用途的明确边界。
- 文档与生产软件行为冲突时，应以可复现的当前行为为准并修正文档。
- 本目录不定义模块划分、类职责、算法实现或开发路线。
