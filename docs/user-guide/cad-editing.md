# CAD 编辑与视图

## 1. 选择

- 单击图元进行单选。
- 从左向右框选时，仅选择完全位于窗口内的图元。
- 从右向左框选时，选择位于窗口内或与窗口相交的图元。
- `Shift + 框选`按图元增量切换选择。
- `Esc`取消当前命令或清空当前交互状态。

已有有效加工顺序时：

- `Ctrl + 框选`把命中的图元扩展为完整加工单元。
- `Ctrl + Shift + 框选`按加工单元整体追加或取消选择。

## 2. 绘图

“默认 → 绘图”提供点、直线、构造线、矩形、多边形、圆、圆弧、椭圆和多段线等入口。

- 矩形和多边形创建为闭合多段线。
- 多段线输入中可在直线段和圆弧段之间切换。
- 当前二维绘图结果位于世界坐标 `Z=0` 平面。
- 参数优先通过光标旁输入面板输入。

## 3. 修改

常用修改包括：

- 移动、复制、旋转、缩放和镜像；
- 矩形阵列和环形阵列；
- 偏移、修剪、延伸和合并；
- 圆角和倒角；
- 图层、颜色和控制点修改。

一次批量修改作为一个撤销单元。使用 `Ctrl+Z` 撤销，使用 `Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。

## 4. 捕捉与约束

底部状态区可控制：

- 端点、中点、圆心和交点捕捉；
- 基点、控制点和网格捕捉；
- 正交；
- 极轴追踪。

光标位置、状态栏坐标和实际取点使用同一约束结果。无法准确取点时，先检查捕捉和正交状态。

## 5. 视图和显示

- 鼠标滚轮缩放视图。
- 使用视图方块切换标准方向。
- 使用适配视图让当前图形进入可见范围。
- “显示”选项卡控制背景网格和加工标记。

加工编号、方向箭头、断面标记和排除图元弱化都是展示结果。关闭显示不会恢复或清除相应加工状态。
