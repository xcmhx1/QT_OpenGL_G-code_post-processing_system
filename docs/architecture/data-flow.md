# 数据流

## 1. 文件导入

```text
DXF / DWG 文件
→ 外部格式解析与适配
→ CAD 文档和原始图元
→ 显示几何
→ Viewer 展示
```

导入边界负责把外部文件转换为可编辑文档。文档建立后，Viewer 从 CAD 层取得显示数据；加工分析从文档捕获独立的业务几何输入。

## 2. 几何转换

```text
CAD 图元
→ 精确源几何
→ 统一加工路径
→ 拓扑和加工分析
```

外部格式对象和 Viewer 显示数据停留在各自边界。拓扑、加工规划和轨迹生成使用统一加工路径，使直线、圆弧、圆、椭圆、多段线和样条进入一致的生产数据流。

## 3. 三轴流程

```text
CAD 几何
+ 用户加工状态
+ 三轴排序策略
→ 三轴加工计划
→ NC 语义
→ G-code 文本
→ 输出文件
```

普通排序优先保留人工设置的加工顺序和方向；智能排序根据几何重新决定顺序和方向。两种排序都输出统一的加工计划，后续 NC 生成仅消费当前有效计划和配置。

## 4. 普通四轴流程

```text
CAD 几何
+ 用户加工状态
+ 旋转轴中心和运动配置
+ 四轴排序策略
→ 四轴加工计划
→ 普通四轴机床轨迹
→ NC 语义
→ G-code 文本
→ 输出文件
```

普通四轴仅要求有效加工路径、旋转轴中心、XYZ/A 运动参数、当前有效加工顺序和配置，对方管截面尺寸、圆角和截面中心无前置依赖。

## 5. 截面增强四轴流程

```text
普通四轴输入
+ 方管 Y/Z 尺寸
+ 圆角半径
+ 截面中心 (Ycenter, Zcenter)
→ 表面归属和截面相关加工分析
→ 方管实体内部路径判断
→ 加工断面 / 废面工艺约束
→ 增强四轴加工计划和机床轨迹
→ NC 语义
→ G-code 文本
```

截面中心位于 YZ 平面，默认值为 `(0, 0)`，即 X 轴。截面增强流程用于方管表面归属、圆角刀头方向、方管实体内部路径、加工断面、废面区间、真实工件碰撞边界和增强安全位置。

没有有效截面尺寸和圆角时，系统跳过截面增强阶段，普通四轴排序、轨迹和导出流程继续使用其自身输入。

## 6. 内部线流程

内部线处理包含两个独立阶段：

```text
统一加工路径
→ 拓扑内部线识别
→ 拓扑排除结果
```

拓扑内部线不依赖方管截面，用于保留连通分量的真实外围闭环并识别其内部横线、竖线、十字线或受支持的曲线路径。

```text
尚未排除的统一加工路径
+ 有效方管截面
→ 方管实体内部路径判断
→ 物理内部排除结果
```

方管实体内部路径阶段依赖有效截面尺寸、圆角和中心。无有效截面时仅跳过该阶段，拓扑内部线阶段仍可执行。

两个阶段的结果写入用户加工状态中的内部线排除输入，并使旧加工计划、机床轨迹和 NC 结果失效。CAD 图元继续保留，可由用户恢复参与加工。

## 7. 用户输入、自动结果与派生结果

```text
用户明确输入
→ 当前加工输入

自动识别或自动排序
→ 候选或计划结果

CAD 几何 + 当前加工输入
→ 加工计划
→ 机床轨迹
→ NC 程序
→ G-code 文本
```

用户确认的手动输入优先于自动识别结果。加工计划、轨迹和 NC 均是派生结果；需要调整最终输出时，应修改上游业务输入并重新生成。
