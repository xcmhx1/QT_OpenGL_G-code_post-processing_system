| 文件名            | 构型描述                                                     | 要求                                               |
| ----------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| 垂直切面.dxf      | 一共八个图元：四个长度为23的直线，与四个长轴和短轴都为1的椭圆。共同围成一个垂直的方管切面，切面的中心位置为(0,0,0)，切面与 x 轴无倾角。 | 能够识别出方管垂直切面，也能被识别为加工断面       |
| 倾斜切面.dxf      | 一共八个图元：四个直线，其中两个长度为23（y轴向），两个长度为26.5581（x轴向），与四个长轴长1.1547，短轴长1的椭圆。共同围成一个倾斜的方管切面，切面的中心位置为(7.2169,0,0)，切面与 x 轴夹角为60°。 | 能够识别出方管垂直切面，也能被识别为加工断面       |
| 垂直&倾斜切面.dxf | 一共16个图元：是前面两个文件的叠加，垂直切面中心位置仍然再(0,0,0)，倾斜切面相对于原来向+x轴方向平移50. | 每一组能够识别出方管垂直切面，也能被识别为加工断面 |
| 倾斜切面2.dxf     | 一共16个图元：可以看作有两个倾斜切面，不过一个离原点较近，一个距离原点较远。 | 每一组能够识别出方管垂直切面，也能被识别为加工断面 |

方管垂直切面的识别都应该一样：识别出的方管长（y轴向），应该为25；宽（z轴向），应该为25，内切圆角半径，应该为1
