# 加工排序与导出

## 1. 加工单元

连续开放链、连续闭环和独立图元都以加工单元参与排序。每个加工单元：

- 在执行序列中保持连续；
- 只显示一个加工编号；
- 只显示一个实际起点方向箭头；
- 编号由当前序列位置连续生成。

## 2. 两种排序

### 排序（保留方向）

普通排序尽量保留：

- 当前仍有效加工单元的相对顺序；
- 人工方向；
- 人工起点。

新增、拆分或合并后形成的新单元按当前自动计划补入。

### 智能排序

智能排序重新计算全部加工单元的：

- 顺序；
- 实际方向；
- 实际起点。

本次计算忽略当前单元序列以及人工方向、起点，但不会删除已经保存的人工状态。内部线、加工断面和废面等工艺状态继续生效。

## 3. 标签和箭头操作

- 单击编号：只选择该加工单元的全部成员。
- `Shift + 单击编号`：追加或取消整个加工单元。
- 双击编号或箭头：反向整个加工单元。
- 选中一段编号连续的加工单元后，`Ctrl + 单击编号`：将目标单元移动到该范围末尾。
- `Ctrl + 框选`：框中命中任一成员时选择完整加工单元。
- `Ctrl + Shift + 框选`：按完整加工单元增量切换。

块内移尾要求选择范围编号连续，目标必须属于该范围。操作可通过统一 Undo/Redo 恢复。

## 4. 计划失效

以下变化会使旧排序失效：

- 新增、删除或修改几何；
- 修改加工启用、方向或起点；
- 修改内部线、加工断面或废面；
- 修改方管截面；
- 修改加工单元序列或遍历；
- 切换影响规划的加工模式或工艺。

失效后重新执行普通排序或智能排序。

## 5. G-code 配置

“机加工 → 配置”区域用于选择当前配置和 G-code 模式。

- **当前配置**：管理配置文件和检索路径。
- **G代码配置**：设置文件、图层、颜色、图元类型代码规则，以及运动安全和四轴参数。
- **加工设置**：设置导入后自动处理和导出路径习惯。

点击 G-code 配置对话框的“确定”后，运动安全和四轴参数会保存到本机设置；点击“取消”不会保存。

## 6. 导出

1. 确认当前 G-code 模式。
2. 确认当前配置和机床参数。
3. 检查编号、箭头、排除状态和加工断面。
4. 点击“G代码导出”并选择目标文件。

当前文档没有有效计划时，导出入口会按当前模式执行智能排序。任一必要阶段失败时停止导出，不写出部分程序。
