# 数据流

## 1. 文件导入

```text
DXF / DWG 文件
→ 外部格式解析与适配
→ CAD 文档和原始图元
→ 显示几何
→ Viewer 展示
```

导入边界负责把外部文件转换为可编辑文档。文档建立后，Viewer 从 CAD 层取得显示数据；加工分析从文档捕获独立的业务几何输入。

## 2. 几何转换

```text
CAD 图元
→ 精确源几何
→ 统一加工路径
→ 拓扑和加工分析
```

外部格式对象和 Viewer 显示数据停留在各自边界。拓扑、加工规划和轨迹生成使用统一加工路径，使直线、圆弧、圆、椭圆、多段线和样条进入一致的生产数据流。

## 3. 加工单元形成

```text
可加工图元
→ 连续关系分析
→ ProcessUnit 集合
→ ProcessUnitSequence
→ ProcessPlan
```

开放或闭合的连续加工组整体形成一个加工单元，不连续的单个图元形成独立加工单元。普通排序、智能排序和人工编排使用同一加工单元集合，不在排序阶段拆分连续单元。

普通排序尽量保留当前加工单元序列、人工方向和人工起点，并将新增或变化的单元补入序列。智能排序忽略当前序列，重新计算全部加工单元顺序，并以结果直接替换当前序列。

## 4. 三轴流程

```text
CAD 几何
+ 当前加工上下文
+ 当前加工单元序列
+ 三轴排序策略
→ 三轴加工计划
→ NC 语义
→ G-code 文本
→ 输出文件
```

两种排序都以加工单元为最小单位并输出统一加工计划。后续 NC 生成仅消费当前有效计划和配置。

## 5. 普通四轴流程

```text
CAD 几何
+ 当前加工上下文
+ 当前加工单元序列
+ 旋转轴中心和运动配置
+ 四轴排序策略
→ 四轴加工计划
→ 普通四轴机床轨迹
→ NC 语义
→ G-code 文本
→ 输出文件
```

普通四轴仅要求有效加工路径、旋转轴中心、XYZ/A 运动参数、当前有效加工顺序和配置，对方管截面尺寸、圆角和截面中心无前置依赖。

## 6. 截面增强四轴流程

```text
普通四轴输入
+ 有效方管截面上下文
→ 表面归属和截面相关加工分析
→ 方管实体内部路径判断
→ 加工断面 / 废面工艺约束
→ 增强四轴加工计划和机床轨迹
→ NC 语义
→ G-code 文本
```

截面增强流程用于方管表面归属、圆角刀头方向、方管实体内部路径、加工断面、废面区间、真实工件碰撞边界和增强安全位置。有效截面上下文的字段见[领域模型](./domain-model.md)，来源见[状态与生命周期](./state-and-lifecycle.md)。

没有有效截面尺寸和圆角时，系统跳过截面增强阶段，普通四轴排序、轨迹和导出流程继续使用其自身输入。

## 7. 内部线流程

```text
统一加工路径
+ 有效方管截面
→ 按有效圆角半径建立安全内缩区域
→ 完整路径内部判断
→ 自动内部线排除结果
```

内部线自动清理依赖有效截面尺寸、圆角和中心。只有整条路径完全位于安全内缩区域内时才进入自动排除结果；安全带附近、接触或穿越内缩边界的路径继续保留。无有效截面时跳过自动清理并提示用户。

自动识别结果写入自动分析状态；用户手动指定或恢复形成用户业务输入。两类状态解析为当前有效的内部线排除结果，并使旧加工计划及其下游结果失效。CAD 图元继续保留，可由用户恢复参与加工。

## 8. 用户输入、自动结果与派生结果

```text
用户业务输入 + 自动分析状态
→ 当前加工上下文

自动识别或自动排序
→ 候选或计划结果

三轴：CAD 几何 + 当前加工上下文
→ 加工计划
→ NC 程序
→ G-code 文本

四轴：CAD 几何 + 当前加工上下文
→ 加工计划
→ 机床轨迹
→ NC 程序
→ G-code 文本
```

用户确认的截面、内部线、加工断面和废面优先于对应的自动分析结果。普通排序尽量保留当前加工单元序列、人工方向和人工起点；智能排序直接替换当前加工单元序列。加工计划、轨迹和 NC 均是派生结果；需要调整最终输出时，应修改上游业务输入并重新生成。
