# 方管四轴

## 1. 适用范围

四轴加工仅适用于绕 X 轴回转、由 A 轴表示周向旋转的当前加工场景。

普通四轴使用：

- 有效加工路径；
- 旋转轴中心；
- XYZ/A 运动参数；
- 当前加工计划和 G-code 配置。

方管截面有效后可增加：

- 方管表面和圆角归属；
- 内部线清理；
- 加工断面和废面；
- 懒旋转区位扫描；
- 真实工件边界参与的安全计算。

## 2. 识别方管截面

1. 选择一个严格闭合截面，或选择其外围边界中的一条图元。
2. 点击“机加工 → 识别方管截面”。
3. 在右侧“方管识别状态”检查 Y 长、Z 宽、圆角半径和识别状态。

候选边界必须真实连续并严格闭合。辅助构造线、内部支线和未连接间隙会影响识别。

自动识别不适合当前文件时，可在右侧输入 Y 长、Z 宽和圆角半径，再点击“应用手动截面”。

## 3. 清理内部线

内部线清理仅在方管截面有效时执行。

系统使用有效圆角半径作为安全内缩距离。只有满足以下条件的完整图元才会被排除：

- 整条加工路径位于截面内部；
- 整条路径到原截面边界的最小距离大于圆角半径和数值安全量；
- 图元不属于加工断面或废面。

安全带附近、接触边界、穿越内缩边界或位于方管表面的图元会保留。清理结果只排除加工，CAD 图元仍可选择和恢复。

## 4. 加工断面

加工断面要求：

- 已有有效方管截面；
- 候选图元形成严格闭合边界；
- 边界能够完整映射到方管外表面；
- 加工后形成明确的工艺中断。

可选择断面的一条边，让系统扩展完整闭环。加工断面作为工艺屏障，其前方加工段内的普通加工单元先完成，然后加工断面。

废面及其影响范围不会进入计划和导出，但原始 CAD 图元保留。

## 5. 懒旋转

懒旋转是可选的截面增强工艺。启用后：

- 按方管区位组织普通加工单元；
- 在约定周向和轴向扫描方向下加工；
- 减少无必要的 A 轴往复旋转；
- 连续链和闭环仍作为完整加工单元，不会被区位扫描拆散。

加工单元无法确定唯一稳定区位时，系统会拒绝生成不安全计划。应检查截面、重复图元、连续关系和路径是否位于支持的表面区域。

## 6. 运动安全

### 旋转安全抬刀距离

跨区位或发生 A 轴旋转时，刀头高于工件旋转包络的安全余量。

### 同区空移离面距离

同一区位加工单元之间空移时的离面距离。设置为 0 时使用贴面转移。

### 联动转移

启用后，系统在安全约束下协调离开、旋转和接近过程。该选项不会放宽连续性或碰撞检查。

### 过切

闭合加工单元先精确回到入口，再沿原方向继续指定距离。设置为 0 时关闭过切。

### 加工面 Z 修正

对四轴加工面位置施加统一补偿。修改后应重新生成轨迹并检查最终安全位置。
