# 领域模型

## 1. 核心概念

| 概念        | 拥有的业务事实                          | 主要关系               |
| --------- | -------------------------------- | ------------------ |
| CAD 文档    | 图元、图层、稳定图元身份和当前几何内容              | 是编辑、几何捕获和显示的文档来源   |
| 精确源几何     | 从 CAD 图元提取的精确业务几何                | 编译为统一加工路径          |
| 统一加工路径    | 规范方向的三维路径、闭合语义和源身份               | 供拓扑、加工分析、规划和轨迹生成使用 |
| 用户加工状态    | 加工启用、方向、起点、人工顺序、内部线、方管截面、加工断面和废面 | 与 CAD 几何共同构成加工计划输入 |
| 加工计划      | 最终顺序、实际方向、实际起点、连续组、排除项和工艺屏障      | 驱动机床轨迹或三轴 NC 生成    |
| 机床轨迹      | XYZ/A 运动、安全移动、连续连接和过切            | 转换为 NC 程序语义        |
| NC 程序     | 与具体文本格式分离的运动和工艺语义                | 由后处理生成 G-code 文本   |
| G-code 文本 | 当前 NC 程序按所选配置格式化后的文件内容           | 是导出边界的最终结果         |

## 2. CAD 文档与稳定身份

CAD 文档保存当前可编辑内容。每个图元具有贯穿文档操作和加工链路的稳定业务身份，后续加工状态、计划、轨迹和 NC 通过该身份关联同一图元。

图层、颜色和原始几何属于文档内容。选择状态和 Viewer 临时缓存仅服务当前交互，不改变稳定业务身份。

## 3. 精确源几何与统一加工路径

精确源几何表示 CAD 图元在业务计算中的几何事实，隔离外部 DXF/DWG 对象和 Viewer 显示数据。
 
统一加工路径是拓扑、加工分析、规划和轨迹生成共同使用的路径表达。不同 CAD 图元通过统一转换进入同一条加工数据链，闭合状态和源图元身份随路径保留。

显示离散结果仅服务 Viewer。显示结果不替代精确源几何或统一加工路径。

## 4. 用户加工状态

用户加工状态是加工流程的业务输入，涵盖：

- 是否参与加工；
- 加工方向和加工起点；
- 人工加工顺序；
- 内部线排除；
- 方管截面尺寸、圆角和中心；
- 加工断面和废面。

业务上，上述内容统一属于用户可设置、修正、清除或恢复的输入。当前生产流程由加工状态和人工排序交互共同向加工计划提供这些输入。

自动识别和自动排序产生候选结果，用户确认的手动输入具有更高优先级。用户通过修改输入重新生成计划、轨迹和 NC，派生结果不反向覆盖用户输入。

## 5. 方管截面

方管截面由以下数据构成：

- Y 方向尺寸；
- Z 方向尺寸；
- 圆角半径；
- YZ 平面上的截面中心 `(Ycenter, Zcenter)`。

截面中心缺失时使用 `(0, 0)`，表示截面中心位于 X 轴。方管截面仅是截面增强四轴功能的输入，普通四轴加工链可以独立运行。

## 6. 加工计划

加工计划将 CAD 几何、用户加工状态和排序策略归并为可执行的加工决定，包括：

- 每个图元的最终加工顺序；
- 实际加工方向和起点；
- 连续加工组；
- 内部线、废面等排除项；
- 加工断面形成的工艺屏障。

加工计划是派生结果。文档内容或相关加工输入变化后，原计划失效并需要重新生成。

## 7. 机床轨迹、NC 程序与 G-code

机床轨迹把加工计划转换为机床运动，表达 XYZ/A 坐标、安全移动、连续连接和过切。普通四轴和截面增强四轴在此阶段使用各自有效的输入边界。

NC 程序保存与文本方言无关的运动及工艺语义。G-code 文本由 NC 程序和当前配置生成，配置决定代码格式和规则应用，但不改变 CAD 几何或用户加工状态。

## 8. 显示结果

加工顺序标签、方向箭头、断面标记和排除样式是加工状态或当前有效计划的可视化投影。Viewer 读取这些结果进行展示，显示缓存和临时选择状态不参与加工事实判定。
